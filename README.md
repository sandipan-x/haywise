# HayWise

Free horse hay calculator: daily hay by body weight, winter season totals, bale counts and cost. No signup.

## Features
- Winter season planner: daily ration x days x horses = total hay to buy
- Bale-type presets (small square, large square, round) with feeder waste adjustment
- Cost estimator plus the cold-snap extra-feed rule
